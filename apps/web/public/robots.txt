# Search engines crawl freely. AI agents are split by what they DO with the
# page, not by whose name is on them: an agent fetching because a reader asked
# is traffic, and an agent hoovering a corpus to train on is not.
#
# The groups below are the whole policy. Read the robots.txt matching rule
# before editing them: a crawler obeys the MOST SPECIFIC group naming it and
# ignores `*` entirely once it has one. That cuts both ways here — the allowed
# agents are listed explicitly for the sake of saying so, but it also means a
# future `Disallow:` added to `*` will NOT reach them. Anything meant for
# everyone has to be repeated into each named group, or those groups deleted.
#
# None of this is enforcement. robots.txt is obeyed voluntarily, and at least
# one agent named below has been documented ignoring it repeatedly. Blocking
# that actually blocks is a firewall rule, not this file.
#
# This list is a snapshot, not a standard. Agents appear, get renamed, and
# split into training and retrieval halves; it needs a pass now and then, and
# an agent nobody has added yet falls through to `*` and is allowed.

# --- Everyone not named below, search engines included ---------------------

User-agent: *
Allow: /

# --- Fetch because a reader asked, right now -------------------------------

Allow: /
